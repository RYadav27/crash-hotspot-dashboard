# Dataset

This project uses the NYC Open Data
"Motor Vehicle Collisions - Crashes" dataset.

The complete dataset is too large to store directly in this GitHub repository.

Download the latest dataset from the official NYC Open Data portal:

https://data.cityofnewyork.us/Public-Safety/Motor-Vehicle-Collisions-Crashes/h9gi-nx95

After downloading the data, place the required CSV file inside this `data/` folder.
